# Breast Cancer Classification ML

## Overview
A supervised machine learning notebook that explores breast cancer data, preprocesses features, trains multiple classifiers, and evaluates classification quality.

## Problem Statement
Cancer diagnosis support requires interpretable classification baselines and comparison between candidate models.

## Features
- EDA and preprocessing
- Multiple classifier comparison
- Classification report and confusion matrix evaluation

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## Dataset
- /content/Breast_Cancer.csv

## Models / Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM
- XGBoost

## Results
The notebook includes classification report and confusion matrix evaluation code. No final metric summary was extracted as a single verified result.

## Project Structure
- notebooks/
  - breast-cancer-classification.ipynb

## How to Run
- `pip install -r requirements.txt`
- `jupyter notebook notebooks/breast-cancer-classification.ipynb`
